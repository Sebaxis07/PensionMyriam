# 06 — Guía rápida (una página, para imprimir)

> **Nota para Codex:** este documento es el CONTENIDO de la hoja de referencia; el formato final (tamaño de letra, disposición, colores, si va plastificada o laminada) se coordina con Codex. Aquí solo se entrega qué debe decir, priorizado como pidió el encargo: reservas, trabajadores, consumos, aseo, conectividad, soporte.

---

## RESERVAS

| Quiero | Hago |
|---|---|
| Reservar | **Reservar** → fechas → elegir pieza → nombre → **Confirmar Reserva** |
| Cancelar | Tocar la pieza → **Cancelar reserva** → escribir motivo → confirmar |
| Enviar comprobante | Después de confirmar: **💬 Enviar por WhatsApp** o **Descargar Comprobante (PDF)** |

**Nunca se cobra abono. Si cancelan, no se cobra nada.**

---

## TRABAJADORES (empresas)

| Quiero | Hago |
|---|---|
| Reservar cama sin el nombre todavía | **Nómina y Camas** → **Reservar camas sin nómina** |
| Poner el nombre cuando llegue | **Identificar cupo N** → escribir nombre → confirmar |
| Registrar su llegada | **Habitaciones** → tocar la pieza → **Registrar ingreso** (solo si ya tiene nombre) |

---

## CONSUMOS

| Quiero | Hago |
|---|---|
| Marcar que alguien comió | **Consumos** → elegir servicio → buscar nombre → **Servir [desayuno/almuerzo/cena]** o **Entregar colación** |
| Marcar a varios a la vez | Seleccionar con el ✓ → **Registrar en lote** |
| Ver quién falta | Filtro **Pendientes** |

**30 contratados que comen 15 siguen facturándose por 30.**

---

## ASEO

| Quiero | Hago |
|---|---|
| Marcar una pieza aseada | Tocar la pieza → **Completar aseo** |
| Marcar varias de una vez | **Aseo de hoy** → **Marcar N diarios listos** |

**Toda pieza ocupada necesita aseo TODOS los días. Nunca se pasa de libre a ocupada sin pasar por aseo.**

---

## CONECTIVIDAD

| Veo esto | Significa esto |
|---|---|
| 🟢 Sincronizado / Al día | Todo llegó a la nube |
| ⚪ Sin red · Guardado local | Sin señal; queda guardado en el teléfono, no se pierde |
| 🟠 Cambios pendientes de envío | Hay señal, enviando lo que faltaba |
| 🔴 N registro(s) necesitan revisión | Toque el círculo para ver qué pasó |

**Nada se pierde sin señal. Solo crear una cuenta nueva o eliminar datos personales necesita internet sí o sí.**

---

## SOPORTE

| Problema | Qué hacer |
|---|---|
| No puedo entrar | Revise correo y contraseña, letra por letra |
| Un botón no aparece | Puede ser normal según su rol — revise su manual |
| Veo un aviso en rojo | Tóquelo, dice exactamente qué pasó |
| Nada de lo anterior funciona | Contacte a: **______________________** (completar en la entrega formal, ver `09-acta-capacitacion-y-recepcion.md`) |
